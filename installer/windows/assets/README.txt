Postiz RU — установка на Windows

1. Запустите Setup.exe (права администратора не нужны).
   Папку payload не удаляйте и не переносите отдельно от Setup.exe.
2. Если Docker Desktop не установлен, установщик предложит поставить его
   (нужны права администратора и, возможно, перезагрузка; после неё снова запустите Setup.exe).
3. После установки на рабочем столе появится ярлык «Postiz RU», а в трее — значок.
   Программа открывается отдельным окном по адресу http://localhost:4007
   (если порт занят, установщик выберет следующий свободный).
4. Первый вход: зарегистрируйте аккаунт владельца. Затем в
   %LOCALAPPDATA%\PostizRU\.env поставьте DISABLE_REGISTRATION=true
   и в меню значка в трее выберите «Перезапустить».

Каналы для российского рынка:
- VK (личная стена) и «VK Community» (стена сообщества от имени сообщества): ключ VK_ID в .env.
- MAX: токен бота с business.max.ru и chat_id канала вводятся при добавлении канала.
- Одноклассники: ключи OK-приложения, вечный access_token и id группы — при добавлении канала.
- Rutube: логин и пароль канала; видео Rutube забирает по ссылке, поэтому нужен публичный адрес.
- Дзен: публикация через Telegram-канал, подключённый к Дзену (см. README в репозитории).

Удаление: «Параметры → Приложения → Postiz RU → Удалить» или ярлык «Удалить Postiz RU» в меню Пуск.
